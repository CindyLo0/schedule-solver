Shift Coverage Solver

Weekly shift preferences for 8 people covering 24 hours a day, 7 days a week.

What this page is for

A team covers a 24-hour day with 8 nine-hour shifts, staggered 3 hours apart. Every person works 5 days and rests 2. This page captures each person's ranked preferences and any hard personal constraints.

When the solver is run, it searches every possible assignment in this browser — there is no server and no precomputed answer. The same inputs always produce the same result, and nothing about the result is hidden or hardcoded.

How to check it yourself

  1. Change a preference below (for example, remove a rest-day pair from one person).
  2. Run the solver and confirm the schedule changes to reflect that edit.
  3. Change it back and confirm the original schedule returns.
  4. Open the page source: scheduler.js holds the search and scoring, app.js holds this interface. Both are plain, readable JavaScript.

People and preferences

Toggle a chip to mark an option acceptable, then drag the ranked list to put the most preferred option first. The highlighted priority is the dimension treated as a requirement.

Run the solver

The search runs exhaustively in this browser tab. The same preferences always produce the same schedule. Editing any preference and pressing Run again recomputes everything from scratch.
